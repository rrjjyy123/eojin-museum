# 온라인 어진 박물관

three.js로 만든 1인칭 관람 웹앱. 전시장 안을 걸어 다니며 조선 왕의 어진을 감상합니다.

## 여는 방법

- **웹 링크** https://claude.ai/code/artifact/186fd8a9-9100-4807-bbed-0fd0006b1eaa
  기본은 비공개입니다. 페이지 우측 상단 공유 메뉴에서 링크를 열어야 다른 기기에서 접속됩니다.
  그 주소로 QR을 만들어 배부할 수 있습니다.
- **오프라인** `어진박물관.html` 파일 하나만 있으면 인터넷 없이 열립니다. USB·공유폴더로 배포해도 됩니다.
  글꼴만 인터넷에서 받아오므로 오프라인에서는 기본 글꼴로 바뀝니다. 내용은 모두 정상입니다.

## 구성

| 공간 | 전시물 |
|---|---|
| 계보의 방 (입구) | 조선 임금 스물일곱 칸의 계보 벽. 얼굴을 확인할 수 있는 어진이 남은 여섯 칸에만 불이 켜져 있습니다 |
| 어진 전시실 | 어진 여섯 점 — 태조 · 세조 초본 · 영조 · **[문]** · 철종 · 고종 · 순종 |
| 특별관 「1954, 불에 탄 얼굴들」 | 1954년 화재로 훼손된 어진 열네 점 |

특별관은 잠겨 있지 않습니다. 어진 전시실 가운데 문으로 걸어 들어가면 됩니다.

## 조작

- 왼쪽 화면을 끌면 걷고, 오른쪽 화면을 끌면 고개를 돌립니다. PC는 W A S D 또는 방향키.
- 그림 앞에 서면 명패가 자동으로 뜨고, 「자세히 보기」로 크게 볼 수 있습니다. 확대·이동 가능.
- 오른쪽 위 전시실 목록을 누르면 그 방으로 바로 이동합니다. 바닥의 금색 선을 따라가도 됩니다.

## 준비 시 확인할 것

- 태블릿에서 3D(WebGL)가 도는지 **실제 기기로 미리 한 번 열어 보십시오.**
  같은 기기에서 미리 열어 두면 다음에 로딩이 빨라집니다.
- 여러 대가 동시에 접속하는 환경이라면 네트워크를 확인하고, 오프라인 파일도 함께 준비하십시오.
- 소장 기관의 이미지 이용 조건(공공누리 유형)을 확인한 뒤 외부에 공개하십시오.

## 고쳐 만들기 및 배포

```
어진박물관 웹앱/
├─ index.html           ← 웹 호스팅(GitHub Pages 등) 진입점
├─ 어진박물관.html      ← 단일 완성본 (오프라인 배포용)
├─ build.py             ← 소스를 합쳐 index.html과 어진박물관.html을 만드는 스크립트
├─ three.min.cjs        ← Three.js r169
├─ assets/              ← 이미지 에셋 (WebP)
├─ 특별관 전시물/        ← 특별관 원본 이미지
└─ src/
   ├─ shell.html        ← 화면 구조와 스타일
   ├─ data.js           ← 명패 문구, 전시 목록, 왕 계보  ← 문구 수정은 여기
   └─ app.js            ← 3D 공간, 이동, 상호작용
```

명패 문구나 데이터를 고칠 때는 `src/data.js`를 수정한 뒤 `python build.py`를 실행하면 `index.html`과 `어진박물관.html`이 자동으로 갱신됩니다.

## GitHub Pages로 배포하기

1. 이 폴더의 내용을 그대로 GitHub 저장소(Repository)에 업로드(Push)합니다.
2. GitHub 저장소의 **Settings** ➔ **Pages**로 이동합니다.
3. **Branch**를 `main` / `/(root)` 로 지정하고 **Save**를 누릅니다.
4. 1~2분 뒤 발급되는 주소(`https://<아이디>.github.io/<저장소명>/`)로 접속하면 배포 완료!
